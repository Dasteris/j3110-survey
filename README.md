# Опрос группы J3110

Статический сайт (без сборки) — еженедельная анкета с карточками по предметам +
дашборд старосты. Данные в Firebase (Firestore + Authentication).

**Сайт:** https://dasteris.github.io/j3110-survey/ · **Дашборд:** `/admin.html`

## Как это устроено

- **Вход:** ИСУ + личный код. У каждого студента аккаунт в Firebase Auth
  (uid = ИСУ, пароль = код), у старосты дополнительно claim `admin`.
- **Доступ проверяет сервер** (`firestore.rules`), а не браузер:
  - студент читает и пишет только свой ответ и только за текущую неделю;
  - все ответы и список группы читает только староста.
- **Неделя** = дата понедельника по Москве (`getWeekId` в `common.js`). Правила
  считают то же по серверному времени. В понедельник 00:00 МСК начинается
  новый пустой документ, прошлые недели остаются для статистики.
- `subjects.js` — предметы, преподаватели и поля карточек. Названия частично
  восстановлены по обрезанному скриншоту расписания — стоит перепроверить.

## Локальные файлы (не в git)

- `roster.local.js` — список группы: ФИО, ИСУ, телеграм, кто староста.
- `codes.local.json` — коды входа `{ "ИСУ": "код" }`.
- Ключ сервисного аккаунта Firebase — держите вне папки проекта.

## Настройка / изменения группы

```bash
npm install
node scripts/setup-firebase.js /путь/до/serviceAccount.json
```

Скрипт можно запускать повторно:

- включает вход по email/паролю, пишет `firebase-config.js`;
- загружает ростер в Firestore, заводит недостающие аккаунты и выдаёт им коды;
- деплоит `firestore.rules`.

Существующие коды он не меняет. Перевыпустить код (старые сессии этого человека
разлогинятся):

```bash
node scripts/setup-firebase.js /путь/до/key.json --reset 558392
node scripts/setup-firebase.js /путь/до/key.json --reset-all
```

Для нового Firebase-проекта сначала один раз вручную в консоли: создать
Firestore Database и нажать **Get started** в Authentication — на это у
сервисного аккаунта нет прав.
