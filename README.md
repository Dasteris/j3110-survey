# Опрос группы J3110

Статический сайт (без сборки) — форма-опрос с карточками по предметам + дашборд
старосты. Данные хранятся в Firebase Firestore.

**Уже задеплоено:** https://dasteris.github.io/j3110-survey/
Firebase-проект `psychology-test-itmo` уже настроен (Firestore, анонимный вход,
правила, ростер группы) — см. раздел "Настройка Firebase" ниже, если нужно
повторить это для нового проекта или переустановить.

## Как это устроено

- `index.html` / `app.js` — логин по ИСУ+фамилии (список в `roster.js`) и
  свайп-карточки с оценками 0–10 (`subjects.js` задаёт предметы и поля).
- `admin.html` / `admin.js` — дашборд, доступен только по ИСУ старосты +
  дополнительному паролю (`adminadmin5252`, задан в `admin.js`).
- Неделя = дата понедельника (`getWeekId` в `common.js`). Каждый понедельник
  00:00 начинается новый пустой документ — то есть "сброс" происходит сам
  собой, а прошлые недели остаются в базе для статистики.
- `firestore.rules` — правила доступа к базе.

## Настройка Firebase (один раз, ~10 минут)

1. Зайдите на https://console.firebase.google.com/ под своим Google-аккаунтом
   → **Add project** → любое имя (например `j3110-survey`) → можно отключить
   Google Analytics, он не нужен.
2. В боковом меню → **Build → Firestore Database** → **Create database** →
   выберите ближайший регион (например `eur3`) → режим **production**.
3. Там же, вкладка **Rules** → вставьте содержимое файла `firestore.rules` из
   этого проекта → **Publish**.
4. В боковом меню → **Build → Authentication** → **Get started** → на вкладке
   **Sign-in method** включите провайдера **Anonymous**.
5. Шестерёнка рядом с "Project Overview" → **Project settings** → внизу
   "Your apps" → нажмите иконку `</>` (Web) → задайте любое имя приложения →
   **Register app**. Firebase покажет объект `firebaseConfig` — скопируйте
   значения (apiKey, authDomain, projectId, storageBucket, messagingSenderId,
   appId) в файл `firebase-config.js` в этом проекте, заменив
   `'ЗАПОЛНИ_МЕНЯ'`.
6. Закоммитьте и запушьте изменения — GitHub Pages подхватит их автоматически.

Бесплатного тарифа Firebase (Spark) с огромным запасом хватит на пару
килобайт данных 24 человек на много лет вперёд.

### Список группы (roster)

ФИО и ИСУ намеренно не лежат в этом (публичном) репозитории — только в
Firestore. Локальный файл `roster.local.js` (в .gitignore, никогда не
коммитится) — источник данных для загрузки:

```bash
npm install
node scripts/setup-firebase.js /путь/до/serviceAccount.json
```

Скрипт загрузит ростер из `roster.local.js` в Firestore, найдёт/создаст веб-
приложение и запишет `firebase-config.js`, включит анонимный вход и
задеплоит `firestore.rules`. Firestore и Authentication должны быть уже
включены в консоли (см. шаги 2 и 4 выше) — это единственное, что скрипт
сделать не может (нужны права владельца проекта, не сервисного аккаунта).

## Публикация на GitHub Pages

Уже настроено при первом деплое (см. сообщение в чате). Чтобы выкатить
изменения после правок:

```bash
git add -A
git commit -m "update"
git push
```

Сайт обновится по тому же адресу за 1–2 минуты.

## Если нужно поправить предметы/преподавателей

Отредактируйте `subjects.js` — названия предметов были восстановлены по
скриншоту расписания и могли обрезаться, поэтому стоит перепроверить.
